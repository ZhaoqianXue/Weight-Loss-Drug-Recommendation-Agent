# WWW 2027：从可合并证据到主动取证

## 结论

选择“跨平台经验的可合并边界”和“证据缺口驱动的取证策略”。研究Web异构情境、重复传播和覆盖失衡是否被融合、检索放大成虚假共识，贡献是融合算子与取证策略。说明书、FAERS不作个体经验真值或发生率金标准。[FDA][fda]

## 问题一：什么经验可以合并？

**问题。**情境约束与来源依赖联合建模，能否使跨Web社区的知识融合减少错误合并，同时保留少数经验？

*Can context- and dependence-aware Web knowledge fusion reduce invalid merges without losing minority experiences?*

**空白。**[LCA13][lca]/[CRH14][crh]研究真值与可靠性；[DART18][dart]已有多真值，[相关源融合14][corr]已有依赖建模，[People on Drugs14][pod]已有健康社区可信度图。缺口不是“考虑多源”，而是以患者、情境限定的经验为对象，联合检验“何时可合并、何时不可计为独立支持”，不把不同人的相反体验当真假竞争。

**方法。**复用抽取、标准化框架与Neo4j加载，新加候选约束与拒配。新增“断言—情境—来源—依赖”子图：保留原文定位、品牌、剂型、适应症、时期、极性；转帖和同人同次经历按断言形成依赖簇，混合帖不整体去重。融合算子只合并符合查询情境的断言，每可辨识依赖簇计一次，输出“证据证书”：适用范围、支持簇、缺失条件。未知情境不补全，未提及不等于否定；未发现依赖不代表独立。

**假设与评测。**相对开发集最强基线，错误合并率下降≥10个百分点，少数经验召回下降≤5个百分点；否则简单分层去重可能已足够。基线为平面关系图、DART＋去重（情境作域）、同字段情境过滤＋去重；消融情境和依赖。用200个测试包测合并精确率/召回率、少数经验保留率；错配情境、重复计数算错误。少数指同情境支持簇较少的显式极性。十倍复制不应增加支持量，新增独立报告则应改变；金标准不裁定药物因果。

**差异。**不同于两篇的关系构建与症状谱，本问题检验融合语义。

## 问题二：下一步应补取什么证据？

**问题。**在相同证据访问权和预算下，按图中证据缺口选择下一次取证，能否减少跨平台问答中的无依据共识？

*Can graph-guided gap-filling reduce unsupported consensus with equal Web evidence access and budgets?*

**空白。**[DRAGged25][drag]已有冲突分类，[MADAM-RAG25][madam]已测证据失衡，[RA-RAG25][ra]按可靠性选源；[MemGraphRAG26][mem]已有图内冲突处理，[HERO-QA26预印本][hero]已审计医学多源分歧。尚待检验的是：面向重复传播和情境不可比，证书驱动的主动取证是否优于静态融合和冲突提示，而非再造分类法。

**方法。**复用现有Agent调用框架，新增检查证书、找原始报告、扩展欠覆盖来源、核验回答四类图工具；按预估“新增可支持断言/调用成本”排序，最多四次调用、总计8千令牌，不训练强化学习。证书给Agent缺口；新取回的原始证据补充图并重算证书，生成答案不写成事实；测试时主图冻结、仅用会话子图。

**假设与评测。**回答覆盖率固定80%时，无依据概括率较开发集最强基线下降≥10个百分点；否则不主张主动策略必要。基线为修复后TableRAG、静态GraphRAG＋DRAGged提示、MADAM-RAG，以及读取同字段的表格ReAct。共用模型、语料和总预算；测风险—覆盖曲线、引用支持率、必要限定条件完整率及调用成本。沿用200题人工允许答案与引用；做“融合有/无×主动取证有/无”交叉消融，并用人工校正图区分抽取误差。

**差异。**两篇均无Agent；这里检验Web取证决策，而非问答演示。

## 数据、参照与统计

沿用固定四分子八品牌。WebMD使用[2,681条有正文评论][readme]；Reddit最多抽取1.2万条帖子及相关自述回复，按品牌、时间、社区分层，不能按症状筛入。补齐381条待抽取正文，先双人标注每平台300个术语提及。由一名临床人员与一名研究者双标、裁决240个自然问题证据包，每包6—10条证据加100条干扰材料：40开发、200测试；按作者、线程、重复簇隔离，覆盖八品牌及证据不足情况。参照含原文、情境、依赖、可答范围，计数另用脚本核对。真实数据为主，复制、遮蔽情境和移除平台为配对压力测试；按原始问题聚类自助法报告95%区间，变体不扩充样本量。
